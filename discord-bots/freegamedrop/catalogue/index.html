DISCORD · SALONS DÉDIÉS

Jeux et DLC
ne jouent pas dans le même salon.

FreeGameDrop sépare les jeux complets des DLC gratuits, comme suggéré pour OverX. Sur Discord, # 🎮・jeux-gratuits reste pour les jeux, # 🧩・dlc-gratuits accueille extensions, packs et cosmétiques. Sur le site, le filtre « Type » fait la même distinction et indique « Toujours gratuit » vs « Offre temporaire ».

✓

Jeux gratuits — titre complet, boutique, prix barré et compte à rebours quand la source fournit une date de fin.

✓

DLC gratuits — extensions, packs et contenus bonus. Le bot distingue « gratuit en permanence » et « temporairement offert ».

✓

Bons plans (plus tard) — réductions non gratuites. Non affiché ici pour garder le catalogue lisible : jeux gratuits uniquement.

✓

Source fiable — GamerPower + API officielle Epic côté bot. Une source DLC dédiée sera ajoutée quand elle sera identifiée.

GitHub Pages = statique.

OverX ne fait pas tourner le bot Python comme un serveur. Le bot publie data/offers.json (ou une API), le site le lit. Pour commencer, le JSON versionné suffit : simple, hébergeable et maintenable. Une petite API pourra le remplacer quand le volume ou les favoris le justifieront.

TRANSPARENCE

Pas de promesse sur ce qu'on ne sait pas.

Ce catalogue n'invente pas d'offre. Il affiche la date de fin quand la source la fournit, indique « Toujours gratuit » quand c'est permanent, et masque les offres expirées. Chaque carte « Récupérer » ouvre la page officielle de la boutique.
